## Project name

Staturefy

## Short description

Client-side player body profiles for Minecraft: choose Vanilla or Chibi for yourself and decide how other players appear to you.

## Full description

**Staturefy** changes how player models look on your client while preserving vanilla gameplay dimensions and hitboxes. Other players do not need to install it, and no profile settings are sent to a server.

### Features

- Choose **Vanilla** or **Chibi** for your own player model.
- Set the default appearance for other players and override it per player.
- Open configuration from Mod Menu or with `/staturefy` and `/staturefy config`.
- Keep settings locally between game sessions.
- Keep using the active player skin and the existing player renderer.

### Requirements

- Minecraft Java Edition 26.3
- Fabric Loader 0.19.5 or newer
- Java 25
- Fabric API
- Mod Menu is optional and adds the Mods-screen configuration button.

### Client only

Staturefy changes local rendering only. It does not alter hitboxes, collision, movement, server data, or network protocol. Install it on the client; no server installation is required.

### Compatibility

Rendering and animation compatibility depends on the exact versions and settings used. Please report the Staturefy, Minecraft, Fabric, mod, and resource-pack versions with a `latest.log` when reporting an issue.
