\# Initial Vision



The goal is NOT to create a "small player".



The goal is to create a modern client-side player rendering framework capable of rendering players using alternative body proportions while remaining highly compatible with the Minecraft Java visual ecosystem.



The first transformation will be:



\- Chibi Player



Future transformations may include:



\- Slime

\- Axolotl

\- Baby Zombie

\- Custom Blockbench models

\- Community morphs



The architecture should be designed with future extensibility in mind.
